# WAMS – Fake Order Blocking Manager

WAMS (Fake Order Blocking Manager) is a custom WordPress and WooCommerce security plugin designed to detect, intercept, and block fraudulent orders, automated bot spam, and malicious checkout attempts before database writes occur.

## Key Features
* **Automated Fraud Detection:** Intercepts suspicious checkout patterns and blocks fraudulent orders.
* **Native WooCommerce Integration:** Hooks directly into native WooCommerce validation and checkout lifecycles for lightweight execution.
* **Admin Management Interface:** Provides a dedicated dashboard screen to inspect, review, and manage flagged orders efficiently.
* **Performance Focused:** Avoids heavy third-party security bloat to maintain fast page load and checkout speeds.

## Tech Stack
* **Backend:** PHP, WordPress Plugin API, WooCommerce Hooks & Filters
* **Frontend/Admin:** WordPress Admin Tables, HTML5, CSS3
